PLATFORM / ROADMAP

From one context to many

Multi-context support needs changes across identity, permissions, collection, storage, discovery, and agent tools. These capabilities are not available yet.

  1. PHASE 1

    Context registry

    Give each context explicit identity, status, visibility, source policy, and contribution policy.

  2. PHASE 2

    Context-scoped access

    Replace global read/write assumptions with permissions tied to a selected context.

  3. PHASE 3

    Discovery and subscriptions

    Let agents list available contexts, inspect details, and subscribe to relevant updates.

  4. PHASE 4

    Cross-context reasoning

    Surface related knowledge, gaps, and conflicts while preserving context boundaries and provenance.
